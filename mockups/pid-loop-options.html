PID loop templates: three on-screen options + config popup

All three show the same loop data (PV, SP, OUT, mode, alarm) in a flat, modern style that still follows ISA-101: neutral grays, blue for setpoint, and color only for alarms. Click each one's hot spot to open the shared configuration popup. Values update live from a simulated loop, so you can change the mode, SP and OUT and watch the response.

Option A — Compact numeric card (168×96 @1080p)

The settings icon button in the header opens the popup. A thin OUT bar sits under the numbers. It's the densest option and good for screens with many loops.

Option B — Bar-graph card (140×150)

A rounded PV bar with a blue SP pointer and orange high/low alarm ticks, plus an OUT bar. The whole card is the click target and lifts on hover. Operators can see at a glance how far PV is from SP.

Option C — ISA instrument bubble + value flag

A P&ID-style instrument bubble (TIC / 101) on the process line, with a rounded value flag tucked behind it. Click the bubble to open the popup. It looks most like the drawings.
