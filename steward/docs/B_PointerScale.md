# EFC/AnalogIndicator/B_PointerScale

<!-- keep:start -->
Vertical scale with limit labels and a side pointer, closest to the built-in Moving Analog Indicator. Use for levels and where trend direction matters. Labels are placed with calc() spacers and collide if two limits are within a few percent.

Binds to PCLib T_KPI via TagPath. No dynamic window (openDock) yet.
<!-- keep:end -->
