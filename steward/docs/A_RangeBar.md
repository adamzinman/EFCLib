# EFC/AnalogIndicator/A_RangeBar

<!-- keep:start -->
Full analog indicator card: tag/description, boxed value, pointer over a zoned bar, min/max and alarm chip. Use on overview and process screens where there is room. Params: LabelMode, ShowMinMax.

Binds to PCLib T_KPI via TagPath. No dynamic window (openDock) yet.
